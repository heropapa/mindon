심덕이 모델링 규격서

심덕이(오리)와 도반 친구들을 다른 작업자가 모델링·개선할 때 지켜야 할 기준. 어디까지 만들어야 하는지, 무엇을 건드리면 안 되는지, 납품 전에 무엇을 확인하는지를 적는다. 모든 생김새의 최종 기준은 컨셉 보드 「심덕」이고, 수치의 기준은 저장소의 characters/character.py와 현재 GLB다.

1. 한 줄 요약

  • 보드대로 생긴 2등신 피규어 톤 캐릭터를, 정해진 뼈대 노드 이름과 피벗 위치를 그대로 둔 채, GLB 한 파일로 낸다.
  • 동작(걷기·가부좌·연잎 숨쉬기·합장·큰절)은 모델이 아니라 로더(duck-glb.js)가 노드를 돌려서 만든다. 그래서 애니메이션을 넣을 필요는 없고, 노드 구조를 바꾸면 안 된다.
  • 납품은 원본 GLB + 라이트 GLB + 렌더 4장 + 소스 파일. 뷰어에서 여섯 동작을 돌려 보고 낸다.

3. 뼈대: 노드 이름과 피벗 (바꾸면 안 되는 것)

본(armature)은 쓰지 않는다. 빈 오브젝트(Empty) 계층에 메시를 자식으로 매단다. 로더는 이름으로 노드를 찾으므로 이름이 하나라도 다르면 그 부위가 움직이지 않는다. 메시는 반드시 아래 노드 아래에 있어야 한다(평평하게 나열하면 합장만 되고 큰절·가부좌가 안 된다).

노드부모위치 (부모 기준, Blender xyz)아래에 매다는 메시로더가 하는 일
root—0, 0, 0없음이동·회전. 소품(좌복·연잎)은 여기
hipsroot0, 0, 0없음앉기·절할 때 y를 −0.14 ~ −0.18 내림
torsohips0, 0, 0.22저고리 몸, 깃·동정, 가방끈, 허리끈, 걸망, 속옷절·반배 때 앞으로 숙임(최대 1.25 rad), 숨쉬기 때 y 1~3.5% 신축

legL legRhips±0.13, 0.02, 0.22다리, 발(물갈퀴·발굽·발바닥)가부좌 때 앞으로 1.55 rad·바깥 0.9 rad 접음

피벗 위치를 ±0.03 이상 옮기면 합장 때 손이 안 모이거나 가부좌 때 발이 몸을 뚫는다. 옮겨야 한다면 로더의 포즈 수치도 같이 바꿔야 하니 먼저 알려 달라.

4. 생김새 기준 (보드와 비교해서 볼 것)

4.1 머리·얼굴

  • 완전한 구가 아니다. 볼이 도톰하고 위가 살짝 좁은 형태(가장 넓은 곳이 중심보다 조금 아래), 앞면은 살짝 납작(앞뒤 0.92). 머리는 몸 위에 겹쳐 앉아 목이 없다.
  • 눈: 크고 세로로 긴 타원(가로 0.16, 세로 0.20), 머리 가운데 높이, 좌우 간격 0.35. 반짝임은 큰 점 하나(위 바깥)와 작은 점 하나(아래 안쪽). 검은자에 흰자 없음.
  • 볼: 눈 바깥 아래에 분홍 타원(가로 0.17, 세로 0.06). 부리/주둥이: 눈 사이 바로 아래, 작게.
  • 심덕이 전용: 머리 위 잔털 3가닥(높이 0.12), 저고리 뒤 밑단 위 꽁지깃 3가닥.

4.2 옷 (기본 법복)

  • 회색 승복 한 벌: 종 모양 저고리(위 지름 0.60 → 밑단 0.92), 넓은 한복 소매(아래 지름 0.38)와 흰 소맷단, 끝에 몸색 손.
  • V자 깃 두 장(오른쪽이 위)이 가슴에서 겹치고 각 깃에 흰 동정 띠. 깃의 윗끝은 턱 아래 어깨선(z 0.78)에서 시작한다. 머리 안쪽에서 시작하면 턱에서 옷이 튀어나와 보인다.
  • 왼쪽 어깨에서 오른쪽 허리로 내려오는 갈색 가방끈 하나(금 버클). 격자 무늬 가사는 기본 법복에 없다('가사 법복' 변형에만).
  • 갈색 허리끈, 매듭은 오른쪽 옆구리에 납작한 매듭 + 끈 자락 두 가닥. 배 앞에 둥근 덩어리를 두지 않는다.
  • 등에 모서리 둥근 갈색 걸망, 어두운 갈색 덮개·멜빵, 금 버클, 분홍 구슬 하나. 거북이는 걸망 대신 등딱지.
  • 띠·끈은 전부 몸 표면에 밀착해야 한다. 몸에서 뜨거나 몸을 뚫고 지나가면 안 된다.

7. 작업 범위: 어디까지 하면 되나

  • 해야 할 것: 모델링(형태·비율·색), 재질 값, 노드 계층과 이름, GLB 내보내기, 라이트 판, 렌더 4장(앞·옆·뒤·합장), 뷰어 확인.
  • 안 해도 되는 것: 애니메이션, 리깅(본), 표정 모프, 텍스처 페인팅, 소품(좌복·연잎은 경내에 있음), 의상 변형(계절 옷·모자는 다음 단계).
  • 하면 안 되는 것: 노드 이름·계층 변경, 피벗 이동, 스케일 적용 안 한 채 내보내기, 卍 등 종단 상징, 한자, 격자 가사(기본 법복), 둥근 배꼽 매듭, 보드에 없는 동물 추가(토끼·곰·판다 등은 사용자 승인 뒤에).

8. 파일 이름과 납품 위치

마음온/brand/avatar/characters/
  maumon-<species>.glb          원본 (simdeok · deerdeer · fox · cat · turtle · sparrow)
  maumon-<species>-lite.glb     라이트 (정점 ≤ 22,000)
  renders/<species>_front.png   앞 · _side.png 옆 · _back.png 뒤 · _hapjang.png 합장  (640×640, 한지색 바탕)
  src/<species>.blend            소스 (또는 character.py 수정분)
심덕이는 추가로 avatar/maumon-duck.glb · maumon-duck-lite.glb 에 같은 파일을 복사한다.

9. 납품 전 확인 절차

  1. GLB를 blender/viewer.html과 같은 폴더에 두고 로컬 서버(python -m http.server)로 연다. 파일 이름을 maumon-duck.glb로 바꾸거나 페이지의 경로를 고친다.
  2. 여섯 동작 버튼을 모두 눌러 본다. 큰절에서 몸이 숙여지지 않으면 메시가 torso 아래에 없는 것이다. 합장에서 손이 안 모이면 wingL/R 피벗이 다른 것이다.
  3. 앞·옆·뒤 시점에서 뜨거나 뚫린 곳을 찾는다. 특히 깃 윗끝(턱), 띠(몸 표면), 발(바닥).
  4. 콘솔에 오류가 없어야 한다. 정점 수는 maumon-<species>.glb를 열어 확인하거나 make_lite.py 출력으로 본다.
  5. 렌더 4장을 보드 옆에 놓고 비교한다. 다르면 보드가 맞다.

10. 검수 체크리스트

  • 키 1.53~1.60, 발바닥 y=0, 원점이 두 발 사이, root 회전 0·스케일 1
  • 노드 10개 이름이 정확히 같고(root·hips·torso·neck·wingL·wingR·legL·legR·eyeL·eyeR), 메시가 해당 노드 아래에 있음
  • 피벗 위치가 표의 값에서 ±0.03 이내
  • 머리가 완전한 구가 아니고 목이 없으며, 눈·볼·부리 위치가 4.1과 같음
  • 깃이 턱 아래 어깨선에서 시작하고 가슴에서 겹침, 동정 띠 있음
  • 가방끈 하나·허리끈·납작 매듭·걸망(거북이는 등딱지). 격자 가사 없음
  • 띠가 몸에 밀착, 어떤 동작에서도 뚫림·뜸 없음
  • 색이 4.3 표와 같음. 재질은 PBR 기본값만
  • 정점 원본 ≤ 60,000 / 라이트 ≤ 22,000, 파일 ≤ 2.5 MB / 1 MB
  • 뷰어에서 여섯 동작 정상, 콘솔 오류 없음
  • 렌더 4장 + 소스 파일 포함, 파일 이름 규칙대로

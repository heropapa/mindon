# 마음온 도반 캐릭터

`character.py <species> <out_dir> [--no-render]` 한 스크립트로 보드의 동물 친구 다섯(여우·고양이·사슴·거북이·참새)과 심덕이를 만든다 (Blender 5.2 bpy). 몸·저고리·소매·가방·다리 피벗은 공통이고 머리 생김새와 발만 종별로 다르다.
GLB 노드 이름(hips·torso·neck·wingL/R·legL/R·eyeL/R)이 전부 같아 `blender/duck-glb.js`(MaumDuckGLB) 하나로 네 캐릭터 모두 움직인다.

| species | 이름 | 특징 | 옷 |
| --- | --- | --- | --- |
| simdeok | 심덕이 (오리) | 크림 몸, 큰 눈, 주황 부리·물갈퀴, 잔털 3가닥, 꽁지깃 3가닥 | 회색 승복, 갈색 가방끈·허리끈 |
| deerdeer | 디어디어 (사슴) | 연한 갈색 몸, 크림 주둥이, 큰 귀, 작은 뿔, 발굽 | 따뜻한 회색 승복 |
| fox | 여우 스님 | 주황 몸, 흰 주둥이, 끝이 검은 큰 귀, 염주 | 갈색 승복 |
| cat | 고양이 도반 | 회색 몸, 흰 입가, 분홍 코, 수염, 둥근 발 | 연회색 승복 |
| turtle | 거북이 도반 | 초록 몸, 연두 입가와 옅은 미소, 걸망 대신 등딱지(능선 3줄), 뭉툭한 발 | 회녹색 승복 |
| sparrow | 참새 도반 | 갈색 몸, 크림 턱, 주황 부리, 머리 옆 깃 무늬, 가는 다리와 발가락 셋 | 연회색 승복 |

파일: `maumon-<species>.glb`(원본, 2.3MB 안팎) / `maumon-<species>-lite.glb`(다른 방문자용, 정점 약 2만). 렌더는 `renders/`.

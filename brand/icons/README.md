# Icons

행동 바·패널용 선 아이콘. 24×24 격자, 선 2px, 끝과 모서리 둥글게, `currentColor`라 글자색을 따른다(패널 위 `paper`, 활성 `gold`, 한지 위 `ink-solid`). 아이콘은 글자 대신이 아니라 글자 위에 놓는다(아이콘 위·한글 아래).

| 파일 | 뜻 | 쓰는 곳 |
| --- | --- | --- |
| place | 장소 (일주문 형태) | 행동 바 '장소' |
| hapjang | 합장 (두 손바닥) | 행동 바 '합장' |
| bow108 | 108배 (엎드린 몸) | 행동 바 '절하기' |
| lotusleaf | 연잎 | 행동 바 '연잎 명상' |
| play / pause / stop | 시작 · 멈춤 · 정지 | 108배·명상 진행 |
| rise | 일어나기 | 앉은 상태 풀기 |
| timer | 타이머 | 명상 시간 |
| speaker / speaker-off | 소리 켜짐 · 꺼짐 | 오른쪽 위 소리 버튼 |
| sun / moon | 보기(시간대·계절·언어) | 오른쪽 위 보기 버튼 (낮엔 해, 밤엔 달) |
| lantern | 등불 | 함께 있기 목록 |

`sprite.svg`를 문서에 한 번 넣고 `<svg width="24" height="24"><use href="#mo-hapjang"/></svg>`로 쓴다. 크기는 24가 기본, 행동 바는 28, 패널 안은 20.

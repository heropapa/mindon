## 2. 배포 — (나) 클라우드 세션 (폰으로 15분)

**① 토큰 만들기 (폰 브라우저, 5분)**
1. dash.cloudflare.com 로그인 → 왼쪽 메뉴 **Workers & Pages** 를 한 번 열기 (처음이면 `<이름>.workers.dev` 하위 주소가 만들어짐 — 이름을 물으면 원하는 것, 예: `mindon`)
2. 오른쪽 위 사람 아이콘 → **My Profile → API Tokens → Create Token → "Edit Cloudflare Workers" 템플릿 → Use template**
   - Account Resources: 본인 계정 / Zone Resources: All zones (또는 mindon.link) → Continue → Create Token → **토큰 복사** (한 번만 보임)
3. 계정 ID: 대시보드 첫 화면 오른쪽(또는 Workers & Pages 오른쪽) **Account ID** 복사

**② 클라우드 환경에 넣기 (2분)** — 채팅에 붙여 넣지 말 것
- Claude 앱 → 이 세션 제목줄의 클라우드 환경 메뉴 → **Edit** → Network secrets(또는 API credentials / 환경 변수)에
  - `CLOUDFLARE_API_TOKEN` = 복사한 토큰
  - `CLOUDFLARE_ACCOUNT_ID` = 계정 ID
- 저장. **기존 세션은 못 읽고 새 세션이 읽음.**

**③ 새 클라우드 세션 열고 이 한 줄 붙여 넣기 (배포·확인은 세션이 함)**
```
마음온 배포해줘: 저장소 heropapa/mindon main 에서 docs/출시_체크리스트.md 2번 ③대로 bash tools/deploy.sh 실행하고 node tools/check_live.mjs <배포 주소> 로 확인한 뒤 결과를 알려줘
```
- 세션이 하는 일: `bash tools/deploy.sh` (빌드 → npm install → 토큰 확인 → 배포 → workers.dev 주소를 공유 미리보기에 넣어 한 번 더 배포) → `node tools/check_live.mjs <주소>` (화면 파일 11개·약관 빈칸·함께 있기 두 명 접속 자동 확인)
- 토큰이 안 읽히면(환경 설정에 넣었는데도 `CLOUDFLARE_API_TOKEN 이 없어요`) Network secrets 대신 **환경 변수** 칸에 같은 이름으로 넣고 새 세션.
- Durable Objects 는 SQLite 방식이라 무료 요금제에서도 됨.

> (가) 로컬 방식이 필요하면: 컴퓨터에 GitHub 로그인·Node 20 설치 후 `bash tools/deploy.sh` 를 `npx wrangler login` 한 뒤 실행 (토큰 대신 브라우저 로그인).

## 3. 도메인 — mindon.link (구매 완료 10/30, 배포 때 자동 연결)

- **따로 할 일 없음.** `server/wrangler.toml` 에 `mindon.link`·`www.mindon.link` 를 Worker 커스텀 도메인(`custom_domain = true`)으로 넣어 둠 → 2번 배포 때 DNS 레코드·인증서가 자동으로 생기고 붙음. `/ws` 도 같은 Worker 라 라우트 따로 없음.
- `ALLOWED_ORIGINS = "https://mindon.link,https://www.mindon.link"`, 공유 미리보기(og:image·og:url·canonical)도 `https://mindon.link` 로 빌드됨 (deploy.sh 기본값).
- 조건: **토큰 계정 = mindon.link 를 산 계정** (네임서버 jihoon/tessa.ns.cloudflare.com). 다르면 배포 끝에 도메인 오류가 나고 workers.dev 주소로만 열림.
- 처음 붙을 때 인증서 발급에 몇 분 걸릴 수 있음 → 그동안 workers.dev 주소로 확인.
- **mindontemple.com**: 소개 홈페이지용 (2026-10-31 변경, 301 취소). 별도 Worker `mindontemple-site` 커스텀 도메인 — DNS 레코드를 손으로 만들지 말 것. `docs/도메인.md`

## 몇 명까지 (2026-10-31 실측 · Workers 유료 요금제)

- **실측**: Cloudflare 위 시험용 서버에 가짜 방문자 1,000명 → 19초 만에 전원 입장, 오류 0, 방 10개(108명씩 꽉 참), 위치 전달 지연 p50 0.33초·p99 0.43초. 꽉 찬 방은 서버 안에서 바로 다음 방으로 넘김(방문자에게 안 보임).
- **구조상 한도**: 방 수 제한 없음(108명씩 자동으로 열림). 빈 방을 정해 주는 안내소 하나가 초당 수백 명 입장까지 처리 → 하루 10만 명(평균 초당 1~2명 입장, 몰릴 때 수십 명)은 여유. 방 인원은 저장소에도 적어 두어 안내소가 잠들었다 깨도 안 잊음.
- **화면 파일**(그림·소리·3D·three.js)은 우리 서버(정적 파일)에서 바로 나감 — 무료·무제한, 바깥 CDN 안 씀(글꼴만 Google).
- **하루 10만 명 요금 추정**: $5 기본 + Durable Objects 요청·실행 시간 초과분 ≈ **월 $50~60(약 7~8만 원)**. 하루 100만 명이면 기획서 §14(월 180~200만 원).
- **오늘 몇 명?** https://mindon.link/stats — 오늘 '마음 켜기'로 들어온 횟수·지금 함께·오늘 최고 동시·최근 14일. 페이지 방문 수는 Cloudflare 대시보드 → mindon.link → 분석.

## 요금 (Cloudflare)

- 화면 파일(그림·소리·모델 15MB)은 정적 파일이라 **무료·무제한** (Worker 를 거치지 않음).
- 함께 있기(/ws)만 한도가 있음. 무료: Durable Objects 하루 요청 10만·실행 13,000 GB-s(방 하나가 하루 약 29시간 깨어 있는 양). 웹소켓으로 들어오는 메시지는 20개 = 요청 1개.
  → 대략 **하루 방문 1천~3천 명**까지 무료. 넘으면 함께 있기만 끊기고(혼자 화면으로 계속) 다음 날 풀림.
- **유료 $5/월**(Workers Paid): 요청 100만·400,000 GB-s 포함, 넘으면 100만 요청당 $0.15 · 100만 GB-s당 $12.50. 출시 홍보를 한다면 유료 권장.
- 하루 100만 명 기준 추정은 기획서 §14 (월 180~200만 원, AI 제외).

## 1. 한 줄 정의

**종교색을 옅게 한 3D 명상 사찰.** 로그인 없이 링크 하나로 들어와 경내를 걸으며
염불·목탁 소리를 듣고, 합장하고, 108배를 하고, 연잎에 앉아 숨을 고르고, 소원 연등을 띄우고,
마음이 무거우면 찻방의 "길잡이"에게 털어놓는다.

### 이름 풀이 — 마음온
"마음 + 온"은 여러 겹으로 읽힌다.
- **온(온기)** — 따뜻한 마음. 차가워진 마음을 데우고 가는 곳
- **온(ON)** — 마음을 켜다. 꺼져 있던 마음에 불(연등)이 들어오는 곳
- **온(오다)** — 마음이 와서 머무는 곳 ("마음이 온 자리")
- **온(온전한)** — 온 마음, 흩어진 마음이 하나로 모이는 곳
- 종교색이 없어 처음 오는 사람에게 가볍다. 부제 **"마음이 쉬어가는 절"** 이 명상 사찰이라는 정체성을 붙잡는다
- 영문: **MindOn** (2026-10-30 본부장 확정. 한 단어, M·O 대문자 — 대문자만 쓰는 자리에서도 MINDON 대신 MindOn). '마음' = mind, '온' = ON(마음을 켜다, 입장 버튼 "마음 켜기"와 맞물림). 처음 쓰던 MindOn 은 외국인이 "마유몬"처럼 읽기 쉽고 해외 'Maum Meditation'(논란 단체)과 겹쳐 바꿈. 정식 주소 mindon.link(2026-10-30 구매, 보조 mindontemple.com → 301). 상표(KIPRIS 9·41·44·45류) 확인은 상표 세션에서 진행 중

### 입장 문 — 불이문 (Gate of Not-Two)
이름이 가볍더라도 공간의 깊이는 첫 문에서 준다.
- 실제 한국 사찰에도 **불이문**이 있다 — 일주문·천왕문을 지나 법당 앞에 서는 마지막 문으로,
  "이 문을 지나면 분별이 사라진다"는 뜻. 마음온의 첫 화면(입장 문)에 `불이문` 현판을 단다 (영문 병기 *Gate of Not-Two*)
- 불이는 *둘이 아니다* — 나와 너, 마음과 세상이 따로 떨어져 있지 않다는 말.
  합장 문구 "여기 온 당신과 이곳은 둘이 아닙니다"와, 다른 방문자의 연등이 함께 떠다니는 2단계 기능으로 이어진다
- 법당 이름은 **고요당(Hall of Stillness)** 으로 둔다 (가칭). 처음엔 '청심당'이었으나 참고 서비스 산사의 '청연당'과 헷갈려 바꿈 (§11)
- 이름 후보였던 불이·소요·고요·숨절·한숨은 검토 후 마음온으로 정리 (2026-10-30)

## 4. 경내 지도 (공간 구성)

```
                    [찻방] 마음 상담 · 3단계
                       │
[일주문] ── 연못길 ── [법당] 염불 · 합장 · 108배 · 1단계
 입장·언어·소리         │
                    [연못] 연잎 명상 · 1단계
                       │
                  [연등 마당] 소원 연등 · 연등 만들기 · 2단계
```

| 장소 | 역할 | 분위기 |
|---|---|---|
| 일주문 | 첫 화면. 언어 선택, "소리를 켜고 들어오세요", 한 문장 인사 | 안개, 멀리 풍경 소리 |
| 연못길 | 걷는 길 자체가 쉼. 자동 걷기 시 가장 오래 머무는 곳 | 돌길, 석등, 대나무 |
| 법당 | 좌복에 앉아 듣기·합장·108배 | 단청, 따뜻한 촛불빛 |
| 연못 | 연잎에 앉아 호흡 명상 — 시점이 물 높이로 낮아짐 | 물결, 반딧불(밤) |
| 연등 마당 | 다른 사람들의 연등이 떠 있는 곳 (2단계) | 수백 개의 연등 불빛 |
| 찻방 | 길잡이와 차 한잔 (3단계) | 낮은 탁자, 찻김 |

**시간대 반영**: 방문자 현지 시각에 따라 새벽(푸른 안개)·낮·노을·밤(연등·별)로 하늘과 조명이 바뀐다.
"밤에 오면 다르다"가 재방문 이유가 된다.

**이동 방식**
- 모바일: 바닥을 탭하면 그곳으로 천천히 걸어감 / 장소 버튼으로 바로 이동 / 화면 드래그로 둘러보기
- PC: 클릭 이동 + WASD
- **안내 따라 걷기**: 버튼 하나로 일주문→연못길→법당→연못을 자동 산책 (멀미 방지 위해 느리고 부드럽게)

## 5. 체험 상세

### 5.1 염불·목탁 듣기 (1단계)
- 법당 앞 좌복에 앉으면 재생 패널이 열린다
- 트랙: **목탁 리듬** / **염불**(1차: 한국저작권위원회 공유마당의 무료 이용 음원, 예: 김용배 「염불소리1」 CC BY 4.0 — 출처 표기) / **범종·풍경 앰비언트** / (추후) 아라 프로젝트 국악 명상곡
- **함께 듣기**: 같은 시간에 들어온 사람들과 같은 염불을 같은 박자로 듣는다 (2단계, 실시간 서버)
- 반복, 수면 타이머(15/30/60분), 화면 꺼도 계속 재생(모바일 백그라운드)
- ⚠ 남의 염불 녹음은 쓰지 않는다 (§8-2)

### 5.2 합장 (1단계)
- 버튼을 길게 누르면 화면 아래에서 두 손이 모이고 종이 한 번 울린다 (본 개발 때 두 손가락 모으기 제스처 검토)
- 합장 후 짧은 문구 한 줄: "잠시 멈추었습니다." / "You paused, and that is enough."

### 5.3 108배 (1단계)
- **빈 방석 가까이 가면** [108배] 버튼이 뜬다 (자리를 정해두지 않음, 다른 사람이 앉은 방석은 제외). 방석 둘레에 금빛 고리
- [시작]을 누르면 죽비 한 번 → **혼자서 천천히** 큰절 (한 번 6초, 108배 약 11분), 절마다 실제 목탁 녹음 한 번. 잠시 멈춤·이어서 가능
- 화면 위 **염주 108알**이 한 알씩 채워짐, 숫자 카운터
- 27·54·81에서 종소리, 108번째가 끝나면 **죽비 세 번** + 마무리 문구
- 누적 기록(오늘/전체 배 수, 연속 방문일)은 기기에 저장

### 5.4 연잎 명상 (1단계)
- 연못의 연잎을 누르면 그 위에 앉는다 — 시점이 물 높이로 낮아지고 주변 소리가 작아짐
- 호흡 가이드 원: **들숨 4초 · 멈춤 4초 · 날숨 6초** (원이 커졌다 작아짐)
- 3 / 5 / 10분 선택, 끝나면 종 세 번

### 5.5 소원 연등 (2단계) — **유료 '연등 달기'로 바뀜 (§17, 2026-10-30)**
- 소원을 적으면 연등이 하늘(또는 연못 위)로 천천히 떠오른다
- 다른 방문자의 연등도 **익명으로** 떠다님 — 누르면 소원 문장만 보임
- 공개/나만 보기 선택, 금칙어 필터·신고·운영자 숨김 (§8-3)

### 5.6 연꽃 연등 만들기 (2단계)
- 꽃잎 색(분홍·흰·노랑·연두…)·모양을 골라 한 장씩 붙여 연꽃 연등 완성
- 완성한 연등으로 소원을 단다 → "내가 만든 연등"이 마당에 남는다
- 간단한 손맛 게임 — 실패 없음, 경쟁 없음

### 5.7 마음 상담 — 찻방의 "길잡이" (3단계)
- 고민을 적으면 길잡이가 **짧고 차분하게** 답한다: 들어주기 → 한 줄 지혜 → 지금 할 수 있는 작은 것(호흡·108배·연등) 권유
- **"AI 스님"이라고 부르지 않는다.** 실제 승려 사칭·종교 권위 오해를 막기 위해 "길잡이(Guide)"로 부르고, AI임을 항상 밝힌다
- 위기 신호가 보이면 답변 대신 즉시 상담 전화 안내 (§8-1)
- 대화 내용은 기본 저장하지 않음
- **유료 회원 전용** (2026-10-30 결정) — 이름·비용·안전 장치는 §15

### 5.8 함께 있음 · 나누기 (참고 서비스에서 가져온 것, 2026-10-30)
- **다른 방문자를 함께 보기** (2026-10-30 변경) — 처음엔 불빛으로 하려 했으나, 3인칭 오리가 생겨 **다른 사람도 각자의 오리로** 보인다 (걷기·앉기·절·숨쉬기 동작까지). 대화는 없음.
  시제품: claude.ai 아티팩트 `room` 기능으로 구현 — 로그인한 조직 구성원·초대 손님끼리만 보임. 정식 공개(누구나 링크로 입장)는 자체 실시간 서버 필요 → 2단계 (Cloudflare Durable Objects / Supabase Realtime 등)
- **초대 링크** — 지금 내가 있는 장소(예: 연못)로 바로 들어오는 링크를 보낸다 (1단계)
- **장면 담기** — 지금 화면을 이미지로 저장·공유 (1단계). 방문자가 스스로 퍼뜨려 주는 장치

## 6. 화면 흐름 (첫 방문)

1. **불이문** — 안개 속 `불이문` 현판, 이름 **마음온**, 부제 "마음이 쉬어가는 절", `한국어 / English`.
   **붓으로 그린 전원(⏻) 로고 버튼**(브랜드 마크, `마음온/brand/`)을 누르면 "마음이 켜지며" 소리와 함께 입장 (마음 **ON**). 작은 글씨로 "소리 없이 들어가기"도 둔다
2. 들어가면 연못길 시작점. 하단에 장소 버튼(일주문·연못길·법당·연못)과 **[안내 따라 걷기]**
3. 법당(고요당) 도착 → 열린 가운데 세 칸 문으로 걸어 들어감. 법당은 폭·깊이 42m, 안 높이 16m (산사 법당처럼). 안은 어두운 나무 마루·회색 방석 11×10줄·연등·드러난 서까래·아래가 트인 큰 옆 창(밖 숲이 보임), 정면 불단에 10m 넘는 부처님(국립중앙박물관 「목조불좌상」 사진)과 뒷벽 가득한 가로형 불화(「아미타극락회도」 덕수448), 모두 공공누리 1유형. [소리 듣기] [108배] [합장]
4. 연못 도착 → [연잎에 앉기] → 명상 시간 선택 → 호흡 가이드
5. 상단에 "오늘 n배 · 명상 n분" (기록은 이 기기에)

## 7. 기술 구성

| 영역 | 1단계 | 2단계 | 3단계 |
|---|---|---|---|
| 3D | Three.js (본 개발: Vite + React Three Fiber/drei) | 동일 | 동일 |
| 다국어 | `ko.json` / `en.json` 분리, 브라우저 언어 자동 선택 + 전환 | 동일 | 동일 |
| 저장 | 기기 저장(localStorage): 108배 누적, 명상 시간, 방문일 | + 서버(Supabase 무료 티어 또는 Cloudflare Workers+D1): 공개 연등 | + 상담 API 서버 함수 |
| 서버 | 없음 (정적 사이트) | 익명 기기 ID, 속도 제한, 신고 | API 키를 숨긴 서버 함수(Cloudflare Worker) → Claude API |
| 호스팅 | GitHub Pages(별도 공개 repo) 또는 Cloudflare Pages | 동일 | 동일 |

- **성능 목표**: 중급 안드로이드폰 30fps, 첫 로딩 5MB 이하 (로우폴리, GLB 압축, 텍스처 최소화, 그림자는 구워 넣기)
- **3D 에셋**: 한국 사찰 무료 모델은 드물다 → 1단계는 단순 도형 조합(그레이박스)으로 시작, 이후 Blender 로우폴리 자체 제작 또는 외주

## 14. 정식 배포 — 하루 100만 명 기준 (2026-10-30)

시제품(claude.ai 아티팩트)은 로그인한 조직 구성원끼리만 서로 보인다. 누구나 링크로 들어와 함께 걷게 하려면 자체 서버로 배포한다.

### 14.1 구성

| 부분 | 서비스 | 하는 일 |
|---|---|---|
| 페이지·작은 파일 | Cloudflare Pages | 화면 코드·텍스처 (무료, 파일 하나 25MiB까지) |
| 큰 파일 | Cloudflare R2 | 부처님·오리 모델, 소리 — **내보내는 전송량 요금 없음** |
| 실시간 방 | Cloudflare Workers + **Durable Objects** | 방마다 작은 서버 하나. 위치를 모아 1초 5번 한 묶음으로 보냄 |
| 회원·결제·공양 기록 | Cloudflare D1 또는 Supabase | 유료 회원·결제 내역 (무료 이용자는 저장 안 함) |
| AI 상담 | Claude API (서버를 거쳐 호출) | 유료 회원만, 하루 횟수 제한 |

### 14.2 방 — 하나에 108명

- **방 하나 정원 108명**. 꽉 차면 새로 오는 사람은 같은 절의 다음 방으로 자동 배정. 친구는 초대 링크(방 이름이 붙은 주소)로 같은 방에.
- 화면: **가까운 30명 정도는 오리**, 나머지는 **등불(빛 점)** — 폰이 버티는 선. 108개의 등불이 경내에 떠 있는 모습 자체가 볼거리.
- 위치는 걸을 때만 1초 4번 보냄(가만히 있으면 0). 사람이 많을 땐 2번으로 낮춤 — 화면은 부드럽게 이어 보여 차이 없음.
- 한 사람이 받는 양 약 10KB/초(약 100kbps) — 폰 데이터로 충분.
- 입구(방 배정) 서버는 여러 개로 나눠 한꺼번에 몰려도 막히지 않게. 출시 전 **부하 시험** 필수.

### 14.3 비용 (하루 100만 명 × 평균 15분, 2026-10-30 공식 요금표로 추정)

| 항목 | 월 비용(추정) | 근거 |
|---|---|---|
| 실시간 방 (Durable Objects) | 약 $1,200 (약 170만 원) | 월 $5 요금제 + 받는 메시지 20개=1건 요청, 100만 건당 $0.15 / 실행 100만 GB-s당 $12.50 / **보내는 메시지 무료** |
| 파일 전송 (R2·Pages) | 약 $50~100 | R2 전송량 무료, 읽기 요청 요금만 |
| 회원·결제 DB | 약 $25~100 | 유료 회원 수에 따라 |
| AI 상담 | 유료 회원 수에 비례 — 회비에서 충당 (§15.3) | |
| 도메인 | 연 1~3만 원 | |
| **합계 (AI 제외)** | **약 월 180~200만 원** | 환율 1달러≈1,400원 |

- 같은 순간에 100만 명이 몰리는 행사(예: 부처님오신날)는 **시간당 약 $100** 수준 — 비용보다 입구 분산·부하 시험이 관건.
- 비교: Supabase Realtime(무료 동시 200명, 유료 500명·메시지 100만당 $2.50)·Ably(무료 동시 200명, 100만당 $2.50)는 **받는 사람마다 메시지를 세서** 108명 방에선 비용이 급증 → 쓰지 않는다.

### 14.4 비용을 줄이는 장치

1. **3D 파일 압축(Draco)** — 부처님 5.6MB·오리 3MB → 각 1MB 안팎. 한 사람이 받는 양 12MB → 약 4MB.
2. 큰 파일은 R2에서, 브라우저·CDN 캐시를 길게(재방문자는 다시 받지 않음).
3. 위치는 걸을 때만, 붐비면 횟수 절반.
4. 방에 사람이 없으면 서버가 잠듦(Hibernation) — 빈 방은 요금 0.

## 15. 유료 회원 — AI 상담 (2026-10-30 결정)

### 15.1 무엇을

- **유료 회원만** 찻방에서 AI와 마음 이야기를 나눈다. 무료 방문자는 지금처럼 로그인 없이 모든 기본 체험.
- 답은 짧고 차분하게: 들어주기 → 부처님 가르침에서 한 줄 → 지금 할 수 있는 작은 것(호흡·108배·연등) 권유 (§5.7).
- 경전 구절을 인용할 땐 출처(경전 이름)를 밝힌다.

### 15.2 이름 — "AI 부처님" 검토 의견

- 사용자 요청은 **"AI 부처님"**. 다만 §5.7에서 "AI 스님"도 쓰지 않기로 했던 이유(종교 권위 사칭 오해)가 부처님에게는 더 크게 걸린다:
  - 신자에게는 AI가 부처님을 **연기**하는 것으로 보여 불경으로 받아들여질 수 있다.
  - "부처님이 이렇게 말씀하셨다"는 식의 답은 **잘못된 가르침을 부처님 이름으로** 퍼뜨릴 위험이 있다.
- 대안 이름(안): **"부처님 말씀 길잡이"**, **"마음 길잡이"**, "법문 길잡이". 부처님은 법당에 계시고, AI는 그 가르침을 **전해 주는 안내자**로.
- 어떤 이름이든: AI임을 항상 밝힘 · 의료·심리치료를 대신하지 않는다고 고지 · 위기 신호엔 109 / 1577-0199 (§8-1).
- 최종 이름은 §10-7에서 결정.

### 15.3 비용 — 회원 한 명당 (Claude API 2026-10 요금)

가정: 상담 1회 = 10번 주고받기, 지침 2천 토큰(캐시 사용), 답 한 번 250자 남짓.

| 모델 | 요금 (100만 토큰당 입력/출력) | 상담 1회 | 회원 1명 월 30회 |
|---|---|---|---|
| Claude Opus 5.5 (가장 섬세) | $4 / $20 | 약 $0.13 (약 180원) | 약 $4 (약 5,500원) |
| Claude Sonnet 5.5 | $2 / $10 | 약 $0.07 (약 95원) | 약 $2 (약 2,800원) |
| Claude Haiku 5.5 (가장 저렴) | $0.10 / $0.50 | 약 $0.006 (약 8원) | 약 $0.2 (약 250원) |

- 마음을 다루는 대화라 **섬세함이 중요** → Opus 5.5 또는 Sonnet 5.5 권장. 비용은 실제 대화로 시험해 확정.
- 회비 안: **월 9,900원** + 하루 상담 횟수 제한(예: 하루 5회) → Opus로도 회원 1명당 남는 구조.
- 안전 장치: 위기 신호 감지 시 AI 답 대신 상담 전화 안내, 하루 횟수 제한, 남용 차단.

### 15.4 로그인·결제

- 로그인: 카카오·구글 (유료 회원만).
- 결제: 웹 정기결제(토스페이먼츠·포트원 등 PG, 수수료 약 3% 안팎). 앱스토어로 팔면 수수료 15~30%라 **처음엔 웹 결제**.
- 해지는 한 번에, 남은 기간까지 이용.

## 16. 공양하기 — 후원 (2026-10-30 결정)

### 16.1 화면

- 컨셉 보드처럼 **금빛 [공양하기] 버튼** (금 바탕 먹 글자). 법당 앞·향로 앞에서, 그리고 로고 메뉴에.
- 누르면: 금액(1,000 · 5,000 · 10,000원 · 직접 입력) → 결제(카카오페이·토스·카드).
- 공양하면 **눈에 보이는 고마움**: 향로에 향이 피어오르거나, 내 이름(또는 '익명')의 연등이 경내에 하루 동안 켜짐. 다른 방문자도 볼 수 있음(이름은 검수, §8-3).
- §8-7: "공양하면 복을 받는다" 같은 말 쓰지 않음. 공양 안 해도 체험은 똑같이.

### 16.2 받는 방식 — **출시 전 법률 검토 필수**

| 방식 | 내용 | 주의 |
|---|---|---|
| ① 운영사 상품 결제 | '연등 켜기'·'향 올리기'를 디지털 상품으로 판매 | 사업자등록·통신판매업 신고, 부가세. 가장 단순 |
| ② 사찰 명의 보시 | 제휴 사찰이 직접 받고, 마음온은 창구 역할 | 사찰 제휴 필요. 종교단체 고유 활동은 규정이 다를 수 있음 |
| ③ 후원 플랫폼 | 후원 서비스(정기·일시 후원) 연결 | 플랫폼 수수료 |

- 불특정 다수에게 **'기부금'으로 모으면 「기부금품의 모집 및 사용에 관한 법률」** 적용 대상일 수 있다 (일정 금액 이상 모집 시 등록 등). **기부금 영수증**(세금 공제)은 지정된 단체만 발급 가능.
- **§17의 연등 달기·기와쓰기가 바로 ①(디지털 공양 상품)** 이다. 그래서 처음엔 ①로 시작하고, 사찰 제휴가 되면 ②를 더하는 안을 권장 — **최종은 변호사·세무사 확인 후** 결정 (§10-8).
- 결제 대행(PG)마다 '기부·종교' 업종 심사가 있으니 신청 전에 업종 분류 확인.

## 17. 유료 상품 — 연등 달기 · 기와쓰기 · 신년운세 · 띠별 운세 (2026-10-30 결정)

절에서 실제로 하는 일(연등 공양·기와 불사)을 온라인으로 옮긴 **디지털 공양 상품**. 전부 유료, 결제는 §15.4와 같은 웹 결제. 기본 체험은 계속 무료(§8-7).

### 17.1 연등 달기

- 연등 색·모양 고르기(연꽃 연등 만들기 §5.6 게임과 연결) → 소원·이름(또는 익명) 적기 → 결제 → **경내에 내 연등이 켜짐**.
- 걸어 둘 기간: 하루 / 한 달 / 부처님오신날까지 등. 밤 경내 연등 길(§13 다음 후보)에 모여 빛난다.
- 다른 방문자에게는 연등 빛과 (공개를 고른 경우) 소원 문장만. 금칙어·신고·검수 (§8-3).
- **이미지로 내려받기**: 내 연등 + 소원 + 이름 + 날짜 + 마음온 낙관을 한 장의 그림(PNG)으로. 휴대폰 배경·SNS 공유용 크기(예: 1080×1350).

### 17.2 기와쓰기

- 절 기와 불사처럼, **기와 한 장에 소원을 붓글씨로** 쓴다. 손가락으로 직접 쓰기 또는 글자를 입력하면 붓글씨 글꼴로.
- 결제 → 기와가 **고요당 옆 '기와 마당'에 쌓이고**, 나중엔 실제로 지붕에 올라가는 연출(달마다 한 줄씩 지붕이 채워짐).
- **이미지로 내려받기**: 먹빛 기와 위 내 글씨 + 날짜 + 마음온 낙관 (예: 1350×1080 가로).
- 실제 사찰과 제휴하면 '진짜 기와에 대신 써서 올려 드림'을 더 비싼 상품으로 (§16.2 ②).

### 17.3 신년운세 · 띠별 운세

- **띠별 운세**: 열두 띠별 올해·이달 운세. 띠만 고르면 됨.
- **신년운세**: 생년월일(선택: 태어난 시)을 넣으면 나만의 한 해 풀이.
- 글은 AI(Claude)가 정해진 틀로 쓰고 운영자가 띠별 원본을 미리 검수. 개인 풀이는 저렴한 모델(Haiku 5.5)로도 1건 1원 안팎 (§15.3 요금 기준).
- 결: 겁주는 말·불길한 예언 없이, **조심할 것 + 마음가짐 + 오늘 해 볼 작은 일(호흡·108배·연등)** 로 끝맺는다. 화면에 "재미로 보는 운세입니다" 고지.
- 생년월일은 풀이에만 쓰고 저장하지 않음(회원이 원하면 저장) — §8-5.
- 참고: 운세는 불교 가르침이라기보다 민속이라, 이름을 '새해 마음 길잡이'처럼 풀지 정할 것 (§10-11).
- **이미지로 내려받기**: 운세 카드 한 장 (공유용).

### 17.4 이미지 내려받기 — 만드는 방법

- 그림은 **방문자 폰(브라우저)에서 바로 그림**(canvas) → 서버 비용 0, 기다림 없음.
- 붓글씨 글꼴·연등/기와 바탕 그림·낙관은 미리 만들어 둠 (디자인 세션, 브랜드 토큰).
- 결제 확인 뒤에만 내려받기 버튼이 열림. 산 기록은 회원이면 '내 공양함'에 남아 다시 받을 수 있음(비회원은 받은 그때만).

### 17.5 가격 안(案)

| 상품 | 안 | 참고 |
|---|---|---|
| 연등 달기 (한 달) | 3,000원 | 부처님오신날까지 5,000원 등 기간별 |
| 기와쓰기 | 5,000원 | 실제 기와 대행(사찰 제휴)은 별도 |
| 띠별 운세 | 1,000원 | 유료 회원은 무료 안 |
| 신년운세 | 3,000원 | 유료 회원은 무료 안 |

- 결제 대행 수수료 약 3% 안팎. 이미지는 폰에서 만들어 추가 비용 거의 없음.
- 가격·회원 혜택은 §10-10에서 결정.

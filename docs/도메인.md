# 마음온 · 도메인과 이름

2026-10-31 기준. 바뀌면 이 문서를 고친다. 결정권자는 본부장.

## 1. 이름

| 항목 | 정한 것 |
|---|---|
| 한글 | **마음온** |
| 영문 | **MindOn** — 한 단어, M·O 대문자. 대문자 자리에서도 `MINDON`·`MIND ON` 대신 MindOn |
| 부제 | 마음이 쉬어가는 절 / a quiet temple online |
| 파일 접두어 | `mindon-` |

영문을 Maumon으로 하지 않은 이유: 외국인이 "마유몬"처럼 읽을 수 있고, `maumon.*` 도메인은 이미 다른 사람이 쓰고 있었다.

## 2. 도메인

| 도메인 | 용도 | 연결 | 상태 |
|---|---|---|---|
| **`mindon.link`** (+ `www`) | 서비스 정식 주소 | Cloudflare Worker `maumon`의 커스텀 도메인 (`server/wrangler.toml` `routes`, `custom_domain = true`) | 2026-10-31 운영 중 |
| **`mindontemple.com`** (+ `www`) | 서비스 소개 홈페이지 | 별도 Worker `mindontemple-site`의 커스텀 도메인 | 바로 공개 (본부장 지시 2026-10-31, 소개페이지 세션 배포) |
| `heropapa.github.io/mindon` | 작업자 문서 (안내문·규격서·캐릭터 시트) | GitHub Pages (main 루트) | 운영 중. 하위 도메인(`docs.mindon.link`)은 붙이지 않기로 함 (2026-10-31 본부장) |

- 두 도메인 모두 2026-10-30에 Cloudflare Registrar에서 샀고, 같은 Cloudflare 계정에 있다. **만료일은 2027-10-30이니 자동 갱신이 켜져 있는지 확인할 것.**
- 처음에 계획했던 `mindontemple.com` → `mindon.link` 301 이동은 취소했다. 소개 홈페이지로 쓰기 때문이다.
- `mindon.place`는 사지 않았다.

## 3. 연결 방식 — 지켜야 할 것

- **DNS 레코드를 손으로 만들지 않는다.** Worker 커스텀 도메인은 배포할 때 DNS 레코드와 인증서를 자동으로 만든다. 같은 이름의 레코드가 미리 있으면 연결이 실패한다.
- 화면 파일과 실시간 방(`/ws`)은 같은 Worker가 같은 주소로 낸다. `/ws`용 라우트를 따로 만들지 않는다.
- `ALLOWED_ORIGINS = "https://mindon.link,https://www.mindon.link"`. 다른 사이트가 우리 방에 붙지 못하게 막는 설정이다. 같은 주소와 workers.dev 주소는 코드에서 늘 허용한다.
- 공유 미리보기(og:image·og:url·canonical)는 `https://mindon.link`로 빌드한다 (`tools/deploy.sh` 기본값).
- 배포에 쓰는 Cloudflare API 토큰은 **도메인을 산 계정에서 만들어야** 한다. 다른 계정의 토큰이면 workers.dev 주소로만 열린다. 토큰은 환경 변수로만 쓰고, 이 공개 저장소에 절대 커밋하지 않는다.
- 나중에 로그인(유료 회원) 기능을 열면 카카오·구글 리디렉트 URI에 `https://mindon.link`를 등록한다.

## 4. 상표

- 특허청 KIPRIS 조회는 본부장이 직접 진행 중이다. 클라우드 세션에서는 KIPRIS 사이트에 접속할 수 없다.
- 무료 공개는 그대로 진행한다. **유료 상품과 AI 상담(마음 길잡이)을 열기 전에는 변리사 검토를 받는다.**
- 조사 세부 내용은 비공개 저장소에 둔다.

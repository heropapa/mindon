# 마음온 · MindOn

마음이 쉬어가는 절 — 인터넷 속에 지어 둔 조용한 명상 사찰. 걷고, 듣고, 절하고, 숨을 고르다 가는 곳.

- 이름: 진행 이름 **마음온** (2026-10-30, 가칭 '불이'에서 변경 — 상표·도메인 확인 후 확정). 입장 문 현판 `불이문`은 유지. 표기는 한글 + 영어 (한자 쓰지 않음).
- 브랜드: `brand/` — 붓글씨 전원 마크(먹·한지·금), 낙관, 아이콘, 토큰, 디자인 시스템 문서
- 기획서: [`docs/기획서.md`](docs/기획서.md) · 보기 좋은 판: `docs/기획서.html`
- 프로토타입(0단계 그레이박스): `prototype/index.html`
  - Claude 아티팩트 형식(doctype·html·body 태그 없음). 브라우저에서 바로 열려면 앞뒤에 `<!doctype html><html><body>` … `</body></html>`를 붙이면 된다.
  - 조작: 바닥 탭 = 걷기, 끌기 = 둘러보기, PC는 WASD도 가능. 하단 장소 버튼 / 안내 따라 걷기.
  - 법당 앞: 소리 듣기(목탁·범종·풍경) · 합장(길게 누르기). 법당 안 빈 방석 옆: 108배(시작하면 혼자 천천히, 끝나면 죽비 세 번). 연못: 연잎에 앉아 호흡 명상.
  - 오른쪽 위 시간 버튼으로 새벽·낮·노을·밤 전환 (기본은 기기 시각).

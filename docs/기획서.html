인터넷 속에 지어 둔 조용한 절. 누구나 들어와 걷고, 듣고, 절하고, 쉬었다 가는 곳.

1한 줄 정의

종교색을 옅게 한 3D 명상 사찰. 로그인 없이 링크 하나로 들어와 경내를 걸으며 염불·목탁 소리를 듣고, 합장하고, 108배를 하고, 연잎에 앉아 숨을 고르고, 소원 연등을 띄우고, 마음이 무거우면 찻방의 "길잡이"에게 털어놓는다.

이름 풀이 — 마음온

"마음 + 온"은 여러 겹으로 읽힌다.

  • 온(온기): 따뜻한 마음. 차가워진 마음을 데우고 가는 곳
  • 온(ON): 마음을 켜다. 꺼져 있던 마음에 불(연등)이 들어오는 곳
  • 온(오다): 마음이 와서 머무는 곳
  • 온(온전한): 온 마음, 흩어진 마음이 하나로 모이는 곳
  • 종교색이 없어 처음 오는 사람에게 가볍다. 부제 "마음이 쉬어가는 절"이 명상 사찰이라는 정체성을 붙잡는다.
  • 영문은 MindOn (2026-10-30 본부장 확정. 한 단어, M·O 대문자 — 대문자만 쓰는 자리에서도 MINDON 대신 MindOn). '마음' = mind, '온' = ON(마음을 켜다, 입장 버튼 "마음 켜기"와 맞물림). 처음 쓰던 Maumon 은 외국인이 "마유몬"처럼 읽기 쉽고 해외 'Maum Meditation'과 겹쳐 바꿈. 정식 주소 mindon.link(2026-10-30 구매), 소개 홈페이지 mindontemple.com, 상표 확인은 상표 세션에서 진행 중.

입장 문 — 불이문 (Gate of Not-Two)

이름이 가볍더라도 공간의 깊이는 첫 문에서 준다.

  • 실제 한국 사찰에도 불이문이 있다. 일주문·천왕문을 지나 법당 앞에 서는 마지막 문으로, "이 문을 지나면 분별이 사라진다"는 뜻. 마음온의 첫 화면에 불이문 현판을 단다 (영문 병기 Gate of Not-Two).
  • 불이는 둘이 아니다. 합장 문구 "여기 온 당신과 이곳은 둘이 아닙니다"와, 다른 방문자의 연등이 함께 떠다니는 2단계 기능으로 이어진다.
  • 법당 이름은 고요당(Hall of Stillness)으로 둔다 (가칭). 처음엔 '청심당'이었으나 참고 서비스 산사의 '청연당'과 헷갈려 바꿨다 (11장).
  • 이름 후보였던 불이·소요·고요·숨절·한숨은 검토 후 마음온으로 정리했다 (2026-10-30).

5체험 상세

5.1 염불·목탁 듣기 1단계

  • 법당 앞 좌복에 앉으면 재생 패널이 열린다
  • 트랙: 목탁 리듬 / 염불(1차: 한국저작권위원회 공유마당의 무료 이용 음원, 예: 김용배 「염불소리1」 CC BY 4.0, 출처 표기) / 범종·풍경 앰비언트 / (추후) 아라 프로젝트 국악 명상곡
  • 함께 듣기: 같은 시간에 들어온 사람들과 같은 염불을 같은 박자로 듣는다 (2단계, 실시간 서버)
  • 반복, 수면 타이머(15/30/60분), 화면을 꺼도 계속 재생
  • 남의 염불 녹음은 쓰지 않는다 (8-2)

5.2 합장 1단계

  • 버튼을 길게 누르면 화면 아래에서 두 손이 모이고 종이 한 번 울린다
  • 합장 후 짧은 문구 한 줄: "잠시 멈추었습니다." / "You paused, and that is enough."

5.3 108배 1단계

  • 빈 방석 가까이 가면 [108배] 버튼이 뜬다. 자리를 정해두지 않고, 다른 사람이 앉은 방석은 제외. 방석 둘레에 금빛 고리
  • [시작]을 누르면 죽비 한 번 → 혼자서 천천히 큰절 (한 번 6초, 108배 약 11분), 절마다 실제 목탁 녹음 한 번. 잠시 멈춤·이어서 가능
  • 화면의 염주 108알이 한 알씩 채워지고 숫자 카운터가 오름
  • 27·54·81에서 종소리, 108번째가 끝나면 죽비 세 번 + 마무리 문구
  • 누적 기록(오늘/전체 배 수)은 기기에 저장

5.4 연잎 명상 1단계

  • 연못의 큰 연잎을 누르면 그 위에 앉는다. 시점이 물 높이로 낮아지고 바람 소리가 작아짐
  • 호흡 가이드 원: 들숨 4초 · 멈춤 4초 · 날숨 6초
  • 3 / 5 / 10분 선택, 끝나면 종 세 번

5.5 소원 연등 2단계 유료 '연등 달기'로 바뀜 (17)

  • 소원을 적으면 연등이 하늘(또는 연못 위)로 천천히 떠오른다
  • 다른 방문자의 연등도 익명으로 떠다님. 누르면 소원 문장만 보임
  • 공개/나만 보기 선택, 금칙어 필터·신고·운영자 숨김 (8-3)

5.6 연꽃 연등 만들기 2단계

  • 꽃잎 색(분홍·흰·노랑·연두…)과 모양을 골라 한 장씩 붙여 연꽃 연등 완성
  • 완성한 연등으로 소원을 단다. "내가 만든 연등"이 마당에 남는다
  • 실패 없음, 경쟁 없음

5.7 마음 상담: 찻방의 "길잡이" 3단계

  • 고민을 적으면 길잡이가 짧고 차분하게 답한다: 들어주기 → 한 줄 지혜 → 지금 할 수 있는 작은 것(호흡·108배·연등) 권유
  • "AI 스님"이라고 부르지 않는다. 실제 승려 사칭이나 종교 권위 오해를 막기 위해 "길잡이(Guide)"로 부르고, AI임을 항상 밝힌다
  • 위기 신호가 보이면 답변 대신 즉시 상담 전화 안내 (8-1)
  • 대화 내용은 기본 저장하지 않음
  • 유료 회원 전용 (2026-10-30 결정). 이름·비용·안전 장치는 15

5.8 함께 있음 · 나누기 1~2단계

  • 다른 방문자는 불빛으로: 지금 경내에 있는 사람들을 아바타 대신 연못 위 반딧불·연등 불빛으로 은은하게 보여준다. 말없이 같이 있다는 느낌은 주되 얼굴·대화는 없다 (실시간 서버 필요 → 2단계, 가능하면 1단계 후반에 인원 수부터)
  • 초대 링크: 지금 내가 있는 장소(예: 연못)로 바로 들어오는 링크 (1단계)
  • 장면 담기: 지금 화면을 이미지로 저장·공유 (1단계)

6화면 흐름 (첫 방문)

  1. 불이문: 안개 속 불이문 현판, 이름 마음온, 부제 "마음이 쉬어가는 절", 한국어 / English. 붓으로 그린 전원(⏻) 로고 버튼(브랜드 마크, 마음온/brand/)을 누르면 마음이 켜지며 소리와 함께 입장 (마음 ON). 작은 글씨로 "소리 없이 들어가기"도 둔다
  2. 들어가면 연못길 시작점. 하단에 장소 버튼(일주문·연못길·법당·연못)과 [안내 따라 걷기]
  3. 법당(고요당) 도착 → 열린 가운데 세 칸 문으로 걸어 들어감. 법당은 폭·깊이 42m, 안 높이 16m (산사 법당처럼). 안은 어두운 나무 마루·회색 방석 11×10줄·연등·드러난 서까래·아래가 트인 큰 옆 창(밖 숲이 보임), 정면 불단에 10m 넘는 부처님(국립중앙박물관 「목조불좌상」 사진)과 뒷벽 가득한 가로형 불화(「아미타극락회도」 덕수448), 모두 공공누리 1유형. [소리 듣기] [108배] [합장]
  4. 연못 도착 → [연잎에 앉기] → 명상 시간 선택 → 호흡 가이드
  5. 상단에 "오늘 n배 · 명상 n분" (기록은 이 기기에)

8반드시 지킬 원칙

  1. 위기 대응: 상담·소원에 자살·자해 신호가 보이면 AI 답변 대신 즉시 안내. 한국 자살예방상담 109 · 정신건강위기상담 1577-0199 / 해외는 지역 핫라인 안내. 첫 화면·찻방에 "의료·심리치료를 대신하지 않습니다" 고지.
  2. 소리 저작권: 이용 허락 없는 염불·독송 녹음 사용 금지. 공유마당 등 CC 라이선스 음원(출처 표기) / 직접 녹음 / 아라 프로젝트 국악 연주자 협업 녹음 중에서.
  3. 공개 소원 검수: 금칙어 필터 + 신고 + 운영자 숨김. 이름·전화번호 등 개인정보 자동 가림.
  4. 존중: 불상·의식을 희화화하지 않는다. 특정 종단 로고·상징은 쓰지 않는다.
  5. 개인정보 최소화: 무료 이용은 로그인 없음. 유료 회원은 결제·로그인에 필요한 최소 정보만, 상담 내용 기본 비저장(저장 시 명시적 동의).

14.2 방: 하나에 108명

  • 방 하나 정원 108명. 꽉 차면 새로 오는 사람은 같은 절의 다음 방으로 자동 배정. 친구는 초대 링크(방 이름이 붙은 주소)로 같은 방에.
  • 화면: 가까운 30명 정도는 오리, 나머지는 등불(빛 점). 폰이 버티는 선. 108개의 등불이 경내에 떠 있는 모습 자체가 볼거리.
  • 위치는 걸을 때만 1초 4번 보냄(가만히 있으면 0). 사람이 많을 땐 2번으로 낮춤.
  • 한 사람이 받는 양 약 10KB/초(약 100kbps). 폰 데이터로 충분.
  • 입구(방 배정) 서버는 여러 개로 나눠 한꺼번에 몰려도 막히지 않게. 출시 전 부하 시험 필수.

15.2 이름: "AI 부처님" 검토 의견

  • 사용자 요청은 "AI 부처님". 다만 5.7에서 "AI 스님"도 쓰지 않기로 했던 이유(종교 권위 사칭 오해)가 부처님에게는 더 크게 걸린다. 신자에게는 AI가 부처님을 연기하는 것으로 보여 불경으로 받아들여질 수 있고, "부처님이 이렇게 말씀하셨다"는 식의 답은 잘못된 가르침을 부처님 이름으로 퍼뜨릴 위험이 있다.
  • 대안 이름(안): "부처님 말씀 길잡이", "마음 길잡이", "법문 길잡이". 부처님은 법당에 계시고, AI는 그 가르침을 전해 주는 안내자로.

  • 결제 대행(PG)마다 '기부·종교' 업종 심사가 있으니 신청 전에 업종 분류 확인.

17유료 상품: 연등 달기 · 기와쓰기 · 신년운세 · 띠별 운세 (2026-10-30 결정)

절에서 실제로 하는 일(연등 공양·기와 불사)을 온라인으로 옮긴 디지털 공양 상품. 전부 유료, 결제는 15.4와 같은 웹 결제. 기본 체험은 계속 무료(8-7).

17.1 연등 달기

  • 연등 색·모양 고르기(연꽃 연등 만들기 5.6 게임과 연결) → 소원·이름(또는 익명) 적기 → 결제 → 경내에 내 연등이 켜짐.
  • 걸어 둘 기간: 하루 / 한 달 / 부처님오신날까지 등. 밤 경내 연등 길에 모여 빛난다.
  • 다른 방문자에게는 연등 빛과 (공개를 고른 경우) 소원 문장만. 금칙어·신고·검수 (8-3).
  • 이미지로 내려받기: 내 연등 + 소원 + 이름 + 날짜 + 마음온 낙관을 한 장의 그림(PNG)으로. 휴대폰 배경·SNS 공유용 크기(예: 1080×1350).

17.2 기와쓰기

  • 절 기와 불사처럼, 기와 한 장에 소원을 붓글씨로 쓴다. 손가락으로 직접 쓰기 또는 글자를 입력하면 붓글씨 글꼴로.
  • 결제 → 기와가 고요당 옆 '기와 마당'에 쌓이고, 나중엔 실제로 지붕에 올라가는 연출(달마다 한 줄씩 지붕이 채워짐).
  • 이미지로 내려받기: 먹빛 기와 위 내 글씨 + 날짜 + 마음온 낙관 (예: 1350×1080 가로).
  • 실제 사찰과 제휴하면 '진짜 기와에 대신 써서 올려 드림'을 더 비싼 상품으로 (16.2 ②).

17.3 신년운세 · 띠별 운세

  • 띠별 운세: 열두 띠별 올해·이달 운세. 띠만 고르면 됨.
  • 신년운세: 생년월일(선택: 태어난 시)을 넣으면 나만의 한 해 풀이.
  • 글은 AI(Claude)가 정해진 틀로 쓰고 운영자가 띠별 원본을 미리 검수. 개인 풀이는 저렴한 모델(Haiku 5.5)로도 1건 1원 안팎 (15.3 요금 기준).
  • 결: 겁주는 말·불길한 예언 없이, 조심할 것 + 마음가짐 + 오늘 해 볼 작은 일(호흡·108배·연등)로 끝맺는다. 화면에 "재미로 보는 운세입니다" 고지.
  • 생년월일은 풀이에만 쓰고 저장하지 않음(회원이 원하면 저장). 8-5.
  • 참고: 운세는 불교 가르침이라기보다 민속이라, 이름을 '새해 마음 길잡이'처럼 풀지 정할 것 (10-11).
  • 이미지로 내려받기: 운세 카드 한 장 (공유용).

17.4 이미지 내려받기: 만드는 방법

  • 그림은 방문자 폰(브라우저)에서 바로 그림(canvas). 서버 비용 0, 기다림 없음.
  • 붓글씨 글꼴·연등/기와 바탕 그림·낙관은 미리 만들어 둠 (디자인 세션, 브랜드 토큰).
  • 결제 확인 뒤에만 내려받기 버튼이 열림. 산 기록은 회원이면 '내 공양함'에 남아 다시 받을 수 있음(비회원은 받은 그때만).

# 심덕이 모델링 규격서

심덕이(오리)와 도반 친구들을 다른 작업자가 모델링·개선할 때 지켜야 할 기준. 생김새의 최종 기준은 **컨셉 보드 「심덕」**, 수치의 기준은 `characters/character.py`와 현재 GLB. 읽기 좋은 판: https://claude.ai/artifact/FBbSs1puLa8vyLK47XPp4H

## 1. 한 줄 요약
- 보드대로 생긴 2등신 피규어 톤 캐릭터를, **정해진 뼈대 노드 이름과 피벗 위치**를 그대로 둔 채, **GLB 한 파일**로 낸다.
- 동작(걷기·가부좌·연잎 숨쉬기·합장·큰절)은 로더(`duck-glb.js`)가 노드를 돌려 만든다. 애니메이션은 필요 없고, **노드 구조를 바꾸면 안 된다.**
- 납품: 원본 GLB + 라이트 GLB + 렌더 4장 + 소스. 뷰어에서 여섯 동작을 돌려 보고 낸다.

## 2. 단위·좌표·크기
| 항목 | 값 | 비고 |
| --- | --- | --- |
| 단위 | 1 = 씬 유닛 | 경내의 "1 단위 = 오리 키" |
| 발바닥 | y=0 (glTF) / z=0 (Blender) | 바닥에 정확히 |
| 키 | 1.53~1.60 (깃털 제외) | 카메라·충돌 크기 기준 |
| 머리 지름 | 0.88~0.93 | 키의 55% 이상, 2등신 |
| 몸 최대 지름 | 0.92 | 머리보다 약간 좁게 |
| 정면 | Blender +Y / glTF −Z | 로더가 180° 돌려 three.js +z |
| 원점 | 두 발 사이 바닥 | root 위치 0·회전 0·스케일 1 |
| 스케일 | 모든 노드 1 (눈만 1, 0.5, 1.25) | 눈 감기용 |

## 3. 뼈대: 노드 이름과 피벗 (바꾸면 안 됨)
본 없이 Empty 계층에 메시를 자식으로 매단다. 로더는 **이름으로** 찾는다. 메시가 노드 아래에 없으면(평평하게 나열) 합장만 되고 큰절·가부좌가 안 된다.

| 노드 | 부모 | 위치(부모 기준, Blender xyz) | 아래 메시 | 로더가 하는 일 |
| --- | --- | --- | --- | --- |
| root | — | 0,0,0 | 없음 | 이동·회전 |
| hips | root | 0,0,0 | 없음 | 앉기·절 때 y −0.14~−0.18 |
| torso | hips | 0,0,0.22 | 저고리, 깃·동정, 끈, 걸망, 속옷 | 숙임 최대 1.25 rad, 숨 신축 |
| neck | torso | 0,0,0.63 | 머리, 눈, 볼, 부리, 귀, 잔털 | 고개 숙임 0.49, 걷기 좌우 0.08 |
| eyeL/eyeR | neck | ±0.175, 0.39, 0.25 | 눈알(+반짝임) | scale.y 0.12 = 감음 |
| wingL/wingR | torso | ±0.41, 0.06, 0.60 | 소매, 소맷단, 손 | 앞 1.25·안 1.0 = 합장 |
| legL/legR | hips | ±0.13, 0.02, 0.22 | 다리, 발 | 앞 1.55·바깥 0.9 = 가부좌 |

피벗을 ±0.03 이상 옮기면 합장·가부좌가 깨진다. 옮겨야 하면 먼저 알릴 것.

## 4. 생김새 기준 (보드와 비교)
**머리·얼굴**: 완전한 구가 아님(볼 도톰, 위 살짝 좁음, 앞 0.92 납작), 목 없이 몸 위에 겹침. 눈은 크고 세로 긴 타원(0.16×0.20), 머리 가운데 높이, 간격 0.35, 반짝임 큰 점+작은 점. 볼은 눈 바깥 아래 분홍 타원. 심덕이는 잔털 3·꽁지깃 3.
**옷(기본 법복)**: 회색 승복, 종 모양 저고리(0.60→0.92), 넓은 소매(아래 0.38)+흰 소맷단, V자 깃 두 장이 **가슴**에서 겹침, 흰 동정, 깃 윗끝은 **턱 아래 어깨선(z 0.78)**. 갈색 가방끈 하나(금 버클). 격자 가사 없음. 허리끈 매듭은 옆구리에 납작하게. 걸망(거북이는 등딱지). 띠는 몸에 밀착.
**색**: 몸 #f9e9b9 · 부리 #f0953f/#d87a2a · 발 #f0953f · 볼 #f2b1a8 · 눈 #1a1714 · 저고리 #c2bdb3 · 깃 #cbc6bc · 동정 #f4f1ea · 가방끈·걸망 #8a6240 · 허리끈 #6b4a30 · 덮개·멜빵 #5a3f28 · 버클 #c9a24f · 구슬 #f08aa6. 다른 동물은 characters/README.md.

## 5. 재질·토폴로지·용량
- 재질: glTF PBR만(Base Color·Roughness·Metallic). 몸 0.55, 옷 0.9, 가죽 0.55, 눈 0.12, 버클 metallic 0.7. three.js r128은 sheen 등을 못 읽음.
- 텍스처: 없어도 됨. 쓰면 ≤1024px, 노멀맵 1장까지.
- 전부 Shade Smooth, 노멀 포함 내보내기.
- 정점: 원본 ≤ 60,000(삼각형 ≤ 150,000), 라이트 ≤ 22,000. 파일: 원본 ≤ 2.5 MB, 라이트 ≤ 1 MB.
- 여섯 동작 모두에서 뚫림·뜸 없음. 애니메이션·스킨 넣지 않음.

## 6. 지원 동작
서 있기(숨 1.2%) · 걷기(다리 ±0.55, 소매 ±0.35) · 가부좌(hips −0.14, 다리 앞 1.55·바깥 0.9) · 연잎 숨쉬기(가부좌+눈 감음+숨 3.5%) · 합장 반배(소매 앞 1.25·안 1.0 → 몸 0.5·머리 0.49 숙임) · 큰절(hips −0.16, 다리 1.45, 몸 1.25, 머리 0.45, 소매 1.7).

## 7. 범위
- 해야 할 것: 모델링, 재질 값, 노드 계층·이름, GLB, 라이트 판, 렌더 4장, 뷰어 확인.
- 안 해도 되는 것: 애니메이션, 본 리깅, 표정 모프, 텍스처 페인팅, 소품, 의상 변형.
- 하면 안 되는 것: 노드 이름·계층 변경, 피벗 이동, 스케일 미적용 내보내기, 卍·한자, 격자 가사, 둥근 배꼽 매듭, 보드에 없는 동물 임의 추가.

## 8. 파일 이름·납품 위치
```
마음온/brand/avatar/characters/
  maumon-<species>.glb        원본 (simdeok · deerdeer · fox · cat · turtle · sparrow)
  maumon-<species>-lite.glb   라이트
  renders/<species>_front|side|back|hapjang.png   640×640, 한지색 바탕
  src/<species>.blend          소스 (또는 character.py 수정분)
심덕이는 avatar/maumon-duck.glb · -lite.glb 에도 복사.
```

## 9. 납품 전 확인
1. `blender/viewer.html`과 같은 폴더에 GLB를 두고 로컬 서버로 연다.
2. 여섯 동작 버튼을 모두 누른다. 큰절에서 몸이 안 숙여지면 메시가 torso 아래에 없는 것. 합장에서 손이 안 모이면 wing 피벗이 다른 것.
3. 앞·옆·뒤에서 뜨거나 뚫린 곳 확인(깃 윗끝, 띠, 발).
4. 콘솔 오류 없음, 정점 수 확인.
5. 렌더 4장을 보드 옆에 놓고 비교. 다르면 보드가 맞다.

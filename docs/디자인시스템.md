# 마음온

**마음온 · 마음이 쉬어가는 절 — MindOn, a quiet temple online.**
인터넷 속에 지어 둔 조용한 절. 로그인 없이 들어와 경내를 걷고, 듣고, 절하고, 연잎 위에서 숨을 고르고 쉬었다 가는 3D 명상 공간입니다. 종교색은 옅게, 공간의 깊이는 깊게.

이름의 "온"은 온기·ON(마음을 켜다)·오다(마음이 온 자리)·온전함을 겹쳐 읽습니다. 로고가 전원 기호인 이유가 여기 있습니다. 영문은 두 단어 **MindOn**으로 씁니다.

원천: **컨셉 보드 「심덕 — 마음이 머무는 곳, 함께 걷는 도반」**(2026-10-30, 모든 디자인의 기준) + 시제품 `마음온/prototype/index.html`의 CSS 변수, 기획서 §1·§2.

## 컨셉 보드가 정하는 것

보드의 그림이 곧 기준이다. 글로 적힌 규칙과 그림이 다르면 그림을 따른다.

- **세계는 따뜻하다.** 낮에는 한지·크림·벚꽃 분홍(`blossom`)과 나무 갈색(`bark`), 밤에는 짙은 남색 하늘(`sky-night`) 위 연등 빛(`lantern`). 먹(`ink-solid`)은 UI 패널과 글자에만 있고, 세계 자체는 먹빛이 아니다.
- **단청은 건물의 것.** `dan-red`·`dan-green`은 기둥·현판·연등 몸체에만. 버튼·칩·옷에는 쓰지 않는다. UI의 강조는 `gold` 하나다.
- **UI 패널은 먹빛 반투명, 글자는 한지.** 보드의 모든 안내 패널(108배 진행, 공양 내역, 상점, 말풍선 바탕)은 둥근 모서리(`radius-md`)의 먹 반투명 판에 흰 글자다. 주 버튼은 `gold` 바탕에 먹 글자(보드의 "공양하기"). 탭은 알약(`radius-pill`), 선택된 탭은 한지 바탕에 먹 글자.
- **진행은 금 막대.** 108배 카운트(53/108), 순례 진행(3/100)처럼 숫자 + 금색 막대. 숫자는 `label` 700, 막대 높이 8px, 바닥은 `line`.
- **말풍선은 흰색.** 방문자 인사말은 흰 바탕 먹 글자 둥근 말풍선. 패널과 구분된다.
- **섹션 제목은 현판 식.** 보드의 각 칸 제목("아바타 꾸미기", "절하기 (108배)")은 먹 반투명 알약에 흰 글자. 페이지 안 제목에도 같은 틀을 쓴다.
- **캐릭터가 주인공.** 어느 화면이든 오리(심덕이)가 보인다. 캐릭터 규격은 아바타 페이지 참조(https://claude.ai/artifact/2WbQLUevXo9ua1ucB9tkQN): 크림 몸, 밝은 회색(`stone`) 저고리, 갈색(`bark`) 가사와 걸망, 주황 부리·발.
- **아이콘은 선 아이콘, 흰색, 한글 라벨 아래 병기.** 보드 하단 행동 바(합장·절하기·염주·명상)처럼 아이콘 위, 한글 아래. 한자 없음.

## 원칙

1. **먹 위에 한지.** 기본 화면은 어두운 경내(`ink-solid`) 위에 먹빛 반투명 패널(`ink`), 그 위에 한지색 글자(`paper`). 밝은 바탕은 문서·안내 화면에만.
2. **단청과 금은 점.** `dan-red`·`dan-green`·`gold`는 현판·낙관·켜진 불빛처럼 작은 면에만 쓴다. 넓게 칠하면 절이 아니라 포스터가 된다. 예외는 보드가 정한 3D 경내의 금빛 불상·등·향로로, 이것은 `gilt`(3D 금속)를 쓴다.
3. **한글 크게, 영어 작게.** 모든 이름은 한글 표제(`display` 계열) 아래 영문을 `en` 12px `paper-dim`으로 병기한다. 한자는 쓰지 않는다. 특정 종단 상징(卍 등)도 쓰지 않는다.
4. **느리게.** 전환 `ease-calm` 600ms, 호흡 원 `breath` 4초, 전원 켜짐 `ignite` 900ms. 급한 움직임은 없다.
5. **모바일·소리 우선.** 패널은 엄지 범위 안, 글자는 15px 이상. 소리 끄기 버튼은 항상 보인다.

## 로고 — 붓글씨 전원 마크

전원 기호(⏻)를 붓글씨 두 획으로 썼습니다. 전원을 켜듯 자리에 앉아 마음을 켜는 순간입니다.

- **첫 획(원호):** 왼쪽 위에서 붓을 눌러 시작해 아래로 돌며 가장 두꺼워지고, 오른쪽 위로 올라가며 가늘어져 갈필로 빠진다. 원은 닫히지 않는다. 열린 틈이 "켜짐"이자 숨 쉴 자리다.
- **둘째 획(수직):** 위에서 눌러 둥글게 시작하고 아래로 가며 가늘어져 끝이 갈라진다. 원호의 틈을 꿰뚫는다.
- **낙관:** 오른쪽 아래 `dan-red` 인장에 한글 "마음". 마크의 1/9 크기, 도장처럼 읽힌다.

| 파일 | 쓰는 곳 |
| --- | --- |
| `assets/Logos/mindon-mark-ink.svg` | 한지 위 먹. 입장 화면의 전원 원판(한지 원판 위), 밝은 문서. |
| `assets/Logos/mindon-mark-paper.svg` | 먹 위 한지. 왼쪽 위 브랜드 표시, 어두운 패널. |
| `assets/Logos/mindon-mark-gold.svg` | 금 단색. 전원을 누른 순간 먹 마크가 이것으로 `ignite` 전환되며 `shadow-glow`가 번진다. 낙관도 금. |
| `assets/Logos/mindon-icon.svg` | 파비콘·앱 아이콘. 먹 바탕 둥근 사각형에 한지 두 획, 붓결 없음. 24px에서도 읽힌다. |

규칙:
- 붓결 마크는 최소 48px. 그 아래는 `mindon-icon.svg` 또는 Wordmark의 선 아이콘.
- 여백은 원호 지름의 1/4 이상. 거친 가장자리를 다른 요소가 건드리지 않게 한다.
- 상자·그라데이션·그림자를 얹지 않는다. 예외는 켜진 상태의 `shadow-glow` 하나.
- 색을 바꾸지 않는다. 세 변형 외의 색이 필요하면 만들지 말고 묻는다.

## 입장 화면의 전원 버튼

`ink-solid` 화면 가운데 `paper` 원판(지름 160~200px, `radius-round`), 그 위에 `mindon-mark-ink.svg`(원판의 60%). 아래에 "마음 켜기" `heading` + "Turn your mind on" `en`.
누르면 원판이 살짝 커지고(scale 1.04), 원판 바탕이 `paper`에서 `ink-solid`로, 마크가 `mindon-mark-gold.svg`로 함께 교차 페이드(`ignite`), 원판 뒤로 `shadow-glow`. 그 뒤 불이문으로 진입.
금 마크는 한지 위에서 2.1:1이라 흐리므로 켜진 상태는 반드시 먹 바탕 위에 둔다. 먹 바탕에 금이 들어와야 "불이 켜진다"가 읽힌다.

## 화면 위 패널 (3D 장면 위 UI)

보드의 UI 칸(108배 진행, 공양, 상점, 친구와 함께)을 기준으로 장면 위에 뜨는 패널의 자리와 생김새를 정한다. 모두 `ink` 반투명 + blur 12px, `line` 1px 테두리, `radius-md`, 글자 `paper`, 패딩 `space-3` `space-4`.

| 왼쪽 위, 워드마크 아래 | **함께 있기** | `lantern` 색 점(지름 8px, 숨 쉬듯 4초 주기 밝기 변화) + "지금 함께 3명" `caption`. 혼자면 "지금 혼자" 대신 점 없이 "조용한 시간" `paper-dim`. 숫자는 `label` 700 `paper`. 누르면 같이 있는 오리 목록(이름 없이 등불 아이콘만) |

## 색

| 역할 | 토큰 |
| --- | --- |
| 바탕 | `ink-solid` (장면), `canvas` (페이지) |
| 패널 | `ink` + blur, 테두리 `line`, `shadow-panel` |
| 글자 | `paper` / `text`, 보조 `paper-dim` / `text-dim` |
| 현판 | 바탕 `ink-solid`, 글자 `gold`, 테두리 바깥→안 `gold` → `dan-green` → `dan-red` |
| 강조 | `gold` 하나 (주 버튼·진행 막대·켜짐). `dan-red`·`dan-green`은 건물·낙관 전용 |
| 세계 | `blossom`·`lotus` 꽃, `bark`·`bark-deep` 나무, `stone` 돌, `tile` 기와, `leaf` 잎, `maple`·`fallen-leaf` 단풍, `water` 물, `cushion` 방석, `lantern`·`lantern-violet` 등, `gilt` 금속, `sky-dawn`·`sky-night` 하늘. 3D 재질은 토큰의 night 값을 쓴다(경내 아트 디렉션 참조) |

대비: 먹 위 `paper` 15:1, `paper-dim` 7.9:1, `gold` 9.4:1. 한지 위 `gold` 원색은 2.1:1이라 밝은 테마에서는 어두운 금(#8a6d1f)으로 바꿔 둔 토큰값을 쓴다. `dan-red`와 `dan-green`은 명도가 비슷하니 둘이 나란히 의미를 나눠 갖지 않게 한다(현판 테두리처럼 장식으로 함께 쓰는 건 괜찮다).

## 타이포그래피

- 표제 **Gowun Batang**, 본문 **Gowun Dodum** (둘 다 Google Fonts, 파일 미포함).
- `plaque` 40px: 현판 글자. `display` 32px: 공간 이름(불이문·고요당). `title` 24px: 패널 제목. `verse` 18px/32px: 염불·안내문, 한 줄 22자 이내.
- `body` 15px/24px, `caption` 13px, `en` 12px 영문 병기, `label` 12px/700 칩.

## 컴포넌트

- **Wordmark** — 마크 + "마음온" + "MindOn". 가로형(왼쪽 위 브랜드)과 세로형(입장·공유 이미지).
- **Plaque** — 현판. 먹 판에 금 글자, 세 겹 테두리, 아래 영문.
- **Button** — 알약. 주(`gold` 바탕 먹 글자), 보조(`line` 테두리 한지 글자), 글자만.
- **Icons** — 행동 바·패널용 선 아이콘 14개 (`assets/Icons/`, sprite.svg).
- **Badge** — 체험 길이·상태 칩.
- **SessionCard** — 체험 한 장(연꽃 위 숨쉬기, 108배, 염불 듣기).
